# QA Debugger Course

Учебный код курса по отладке Python для QA и начинающих разработчиков. Основной инструмент — PyCharm. Теория, постановки заданий и формы ответов находятся в Stepik.

## Как получить код

В шаге Stepik открывайте ссылку на нужный файл или каталог. Короткий файл можно скопировать с GitHub в локальный файл с тем же именем. Для проекта с несколькими файлами скачивайте весь репозиторий кнопкой Code → Download ZIP, распаковывайте его и открывайте корневую папку в PyCharm. Это скачивание с GitHub; вложения Stepik не используются.

При работе с Git можно клонировать репозиторий и перейти на версию, указанную в шаге. Знание Git не является предварительным требованием курса. Для зафиксированных версий используйте ссылку на скачивание из урока, а не произвольное состояние основной ветки.

Выберите локальный интерпретатор Python, откройте нужный .py и выполните Run или Debug по инструкции задания. Дополнительные пакеты и аргументы не нужны. Код модулей 1 и 2 проверен на CPython 3.12.14. Код модуля 3 проверен на CPython 3.12.14 и 3.13.5. Проверка в PyCharm проводится отдельно.

## Структура

Каждый модуль — отдельная папка в modules/. Внутри — пронумерованные уроки. Примеры находятся в examples/, самостоятельные исследования — в practice/ с отдельным каталогом для каждого задания. Если упражнению нужны данные или несколько модулей, они располагаются внутри его каталога; данные — в data/.

Учебный код может содержать намеренные дефекты. Не исправляйте их, если этого не требует задание. Решения, эталонные ответы, тестовые ключи и авторские материалы в этот репозиторий не входят.
